# Лабораторная работа 2 — Петрова Анна, АБс-526

Номер в списке: **19**. Задание 5: специальный вариант **«*» — Хаффман**.
Все задания объединены в одном `main.cpp`. Язык C++11.

| Задание | Вариант | Реализация |
|---|---|---|
| 1 | 19 % 10 = 9 | Бейсбол, собственный стек из ЛР1 |
| 2 | общий | Set на собственной хеш-таблице с цепочками |
| 3 | 19 % 6 = 1 | Разбиение множества на группы с заданной равной суммой |
| 4 | 19 % 6 = 1 | Все различные подмножества массива |
| 5 | * | Кодирование и декодирование Хаффмана |
| 6.1 | нечётный номер | Линейное пробирование и двойное хеширование |
| 6.2 | 19 % 9 = 1 | Метод свёртки |
| 7 | нечётный номер | LRU-кэш |

В задании 4 следуем примеру ТЗ с `{x,z}`: выводятся все подмножества, а не только непрерывные подмассивы. Повторяющиеся значения не создают одинаковых результатов.

## Сборка и запуск

```sh
make
./build/lab2
./build/lab2 1
./build/lab2 --help
```

Если используется GCC: `make CXX=g++`. Номер 1–7 запускает задание без меню. Числа хранятся в `int`, хеши — в `unsigned int`; переполнение входных очков и сумм проверяется.

## Примеры ввода

1. `./build/lab2 1`, строка `[5, 2, C, D, +]` → 30.
2. Множество сохраняет каждое значение в отдельной строке файла:

```sh
./build/lab2 --file set.txt --query 'SETADD 5'
./build/lab2 --file set.txt --query 'SET_AT 5'
./build/lab2 --file set.txt --query 'SETDEL 5'
./build/lab2 --file set.txt --query 'SETPRINT'
```

Значение — один непустой токен без пробелов. Неоткрывшийся входной файл считается пустым множеством; ошибка открытия выходного файла сообщается. Операции таблицы в среднем O(1), чтение и запись всего файла O(n).

3. `./build/lab2 3`: строка `{4,10,5,1,3,7}`, затем `15` → две группы; с `10` → три. Цель вводится отдельно. Используется полный поиск с возвратом, а не жадное распределение.
4. `./build/lab2 4`: `3`, затем `x y z` → восемь подмножеств, включая пустое. Алгоритм экспоненциальный; использовать небольшие массивы.
5. `./build/lab2 5`: строка `abracadabra`, затем пустая строка → частоты, коды, кодирование и обратная расшифровка. Можно ввести свои биты для декодирования по этому же дереву. Обработка побайтовая; UTF-8 восстанавливается без потери байтов.
6. `./build/lab2 6`: режим `1`, ключ `523456795` → `523+456+795 = 1774`; режим `2` → измерения; режим `3` → расположение коллидирующих ключей. Сравнение и методика — в `report/hash_comparison.md`.
7. `./build/lab2 7`: `2 8`, затем `SET 1 2 SET 2 3 SET 1 5 SET 4 5 SET 6 7 GET 4 SET 1 2 GET 3` → `5 -1`. Первые числа — ёмкость и число запросов. GET и обновление SET делают ключ последним использованным.

## Файлы

- `struct_cplas/Array`, `Stack`, `spisok` — структуры Ann из первой лабораторной; удалён служебный вывод при удалении узла списка.
- `struct_cplas/hash` — таблица с цепочками и открытая адресация.
- `struct_cplas/Mnozh` — АТД Set; `tree` — дерево Хаффмана; `cache` — LRU.
- `zadachi` — семь заданий; `utils` — проверка положительного int.
- `report` — отчёт Word, сравнение таблиц и результаты проверок.

Проверено: сборка C++11 с `-Wall -Wextra`, 137 проверок консольных сценариев, 48 000 случайных операций хеш-таблиц и 27 000 операций LRU относительно эталона; проверки с AddressSanitizer и UndefinedBehaviorSanitizer. Все семь заданий также запущены через одно меню.
